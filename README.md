# Students-Performance-Analysis/Python
This repo contains a beginner-friendly students analysis project done in Python 

## Tools Used
- Microsoft Excel
- Python

## Project Overview
This project explores how student background and preparation affect exam performance. It looks at math, reading and writing scores and identifies which factors are linked to higher or lower results, then offers recommendations that schools or education programs could act on.
Key questions explored:
- How do average math, reading and writing scores compare?
- Do male and female students perform differently across subjects?
- Does completing a test preparation course improve scores?
- How does parental level of education relate to student performance?
- Does the type of lunch (standard vs free/reduced) relate to scores?
- How do the different race/ethnicity groups compare?

## Dataset
The dataset [StudentsPerformance.csv] contains 1,000 students and 8 columns:
Column	Description
- Gender:	Male or female
- Race/Ethnicity: Anonymized group (A to E)
- Parental Level of Education:	From some high school up to master's degree
- Lunch: Standard or free/reduced
- Test Preparation course: None or completed
- Math score:	Score from 0 to 100
- Reading score: Score from 0 to 100
- Writing score: Score from 0 to 100
